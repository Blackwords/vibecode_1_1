# Project 0: Контрольна панель (Dashboard)

Це сучасний веб-додаток для моніторингу курсу криптовалют, планування завдань та персоналізації робочого простору. Проект створений з використанням чистих технологій HTML, JavaScript та Tailwind CSS.

## 🚀 Основні функції

-   **Курс BTC до UAH**: Отримання актуального курсу біткоїна в режимі реального часу через CoinGecko API.
-   **Калькулятор валют**: Швидкий розрахунок вартості BTC у гривнях на основі поточного ринкового курсу.
-   **Тренд цін**: Візуальне відображення динаміки ціни (зростання/падіння) з іконками та таймером тривалості тенденції.
-   **План навчання (To-Do List)**: Зручний список справ з можливістю додавання, відмітки про виконання та видалення. Виконані завдання автоматично переміщуються в кінець списку.
-   **Персоналізація статусу**: Можливість встановити власний вітальний текст або статус, який зберігається після оновлення сторінки.
-   **Темна та світла теми**: Перемикач інтерфейсу між світлим та темним режимами для комфортної роботи у будь-який час доби.
-   **Persistence (Збереження даних)**: Всі ваші дані (статус, список справ, обрана тема, останній відомий курс) зберігаються у `localStorage` браузера.

## 🛠 Технології

-   **HTML5** — структура сторінки.
-   **Tailwind CSS (CDN)** — сучасний та адаптивний дизайн.
-   **JavaScript (Vanilla JS)** — логіка додатку, робота з API та LocalStorage.
-   **CoinGecko API** — джерело даних про ціну криптовалют.

## 📦 Як розгорнути на GitHub Pages

Щоб ваш проект став доступним за посиланням в інтернеті, виконайте ці кроки:

1.  **Створіть репозиторій на GitHub**:
    -   Зайдіть на [github.com](https://github.com/) та створіть новий публічний репозиторій з назвою `project-zero`.
2.  **Завантажте файли**:
    -   На сторінці репозиторію натисніть **"uploading an existing file"**.
    -   Перетягніть у вікно браузера всі файли та папки вашого проекту (`index.html`, `js/`, `css/`, `assets/`, `README.md`).
    -   Натисніть **"Commit changes"**.
3.  **Увімкніть GitHub Pages**:
    -   Перейдіть у вкладку **Settings** вашого репозиторію.
    -   У лівому меню оберіть **Pages**.
    -   У розділі **Build and deployment > Branch** оберіть гілку `main` (або `master`) та папку `/ (root)`.
    -   Натисніть **Save**.
4.  **Готово!**:
    -   Через 1-2 хвилини зверху з'явиться посилання на ваш сайт (наприклад, `https://username.github.io/project-zero/`).
